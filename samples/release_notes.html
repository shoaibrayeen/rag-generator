NorthwindOS 4.2 Release Notes

Released 14 August 2026. NorthwindOS 4.2 is a long-term support release supported until August 2029.

New features

  • Path planner now supports dynamic obstacle avoidance at up to 2 m/s for Rover bases.
  • The Atlas arm family gains force-limited hand guiding; the default collision threshold is 80 N.
  • Fleet Manager can now schedule firmware updates in maintenance windows.

Breaking changes

  • The legacy REST API v1 has been removed. Integrations must migrate to API v2 before upgrading.
  • Minimum controller firmware is 3.9.0.

Known issues

Vision Kit calibration may fail under flickering LED lighting; a fix is planned for 4.2.1.
